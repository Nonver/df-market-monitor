# 三角洲行动 · 子弹价格监控平台

交易行子弹价格的采集、监控与择时信号平台。含**用户端网站**、**微信小程序**和**管理后台**。

---

## 一、快速启动

双击 `server/start.bat`，或命令行：

```bash
cd server
python -m uvicorn app.main:app --host 0.0.0.0 --port 8765
```

启动后访问：

| 地址 | 说明 |
|---|---|
| **http://127.0.0.1:8765/** | 用户端网站（行情、走势、买入机会） |
| **http://127.0.0.1:8765/admin** | 管理后台（凭证、子弹、配置、采集） |
| http://127.0.0.1:8765/docs | API 接口文档（Swagger） |
| http://127.0.0.1:8765/openapi.json | 接口清单（43 条路由） |

**管理后台账号**：首次访问 `/admin` 时输入任意用户名与密码，即自动创建第一个管理员（请自行设置强口令）。

## 三、拿凭证

### 方式一：扫码自动获取（推荐，30 秒搞定）

管理后台 →「凭证管理」→ **扫码获取凭证** → 手机 QQ 扫 → 完事。

系统会自动拿凭证、加密入库、打接口验证，全程不用抄任何字符串。

原理：登录二维码是公开可申请的标准 OAuth 流程。服务端自己申请一个二维码，
你扫，腾讯就把授权给我们申请的这个会话。**凭证从腾讯直接进你的数据库，
不经过任何第三方平台。**

### 方式二：手动填写（扫码失败时的兜底）

浏览器打开官方周报页，扫码登录后从 URL 或 F12 里抄出凭证：

```
https://df.qq.com/cp/weekly20241129/index.html
```

| 字段 | 说明 |
|---|---|
| `openid` | 登录后 URL 参数或 F12 网络请求里 |
| `access_token` | 同上 |
| `acctype` | QQ 登录填 `qc`，微信登录填 `wx` |

拿到后：管理后台 →「凭证管理」→ 手动添加 → 点「测试」。
返回 `ret:0` 且带价格即成功。

> 该页面的 `appid` 与价格接口同为 `101491592`，凭证通用 —— 这是这条路能走通的原因。

## 四、拿到凭证后

1. **替换 propid**：管理后台 →「子弹管理」→ 批量导入 propid
   （抓包时顺带把 46 种子弹的官方 11 位 ID 抄下来，按名称匹配导入）
2. **历史回填**：管理后台 →「采集中心」→ 回填 14 天（限速 1 秒 1 次，约 1 小时）
3. **重建基准**：采集完成后点「重建日内基准」
4. **开启定时**：「系统配置」里 `collect_enabled=1`、`collect_interval=60`（每小时采一次）

## 六、策略要点

**成本结构**（S9 赛季实测）：保证金 3%（上架即扣、流拍不退）+ 手续费 5%(12h)/8%(24h)。
盈亏平衡需涨 **8.7%**，故策略门槛设为 **15%** —— 低于此线的波动系统直接过滤，不做。

**为什么只做子弹**：交易行里枪械、护甲、配件、钥匙买了即绑定无法转卖，
只有可堆叠的弹药不绑定，能反复低买高卖。

**采集架构**：只在服务端采集。价格是公共数据，服务端采一次全平台共享，
请求量与用户数无关（固定 1104 次/天）。小程序端绝不直连官方接口（凭证会暴露）。

## 七、配置与安全

- 数据库凭据在 `server/app/core/database.py`，可用环境变量覆盖：
  `DB_HOST` `DB_PORT` `DB_USER` `DB_PASS` `DB_NAME`
- 凭证加密密钥：环境变量 `DF_SECRET_KEY`（默认开发密钥，**上线前务必修改**）
- `access_token` 在数据库中 AES 加密存储，接口返回一律打码
- 扫码登录参数在「系统配置 → 扫码登录」，腾讯若改协议改这里即可，不用动代码。
  **注意 `qr_client_id` 必须与 `ams_appid` 一致**，否则扫码成功但接口不认

**手机真机调试**：改 `DF/utils/api.uts` 顶部的 `BASE_URL` 为本机局域网 IP。

## 八、合规

- 仅采集公开物价数据，不介入游戏客户端
- 不涉及 RMT（哈夫币兑换现金），不做交易撮合 —— 这是官方红线
- 采集频率 ≥ 1 小时一次，不干扰官方服务
- 价格以游戏内为准，数据版权归腾讯所有
